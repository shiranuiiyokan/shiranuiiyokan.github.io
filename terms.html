利用規約

制定日・最終更新日：2026年9月11日

DogVideoFactory（以下「本システム」）は、運営者本人が所有するYouTubeチャンネルへ犬種解説動画をアップロードし、予約公開するための非公開・個人用システムです。

1. 利用者

本システムは運営者本人のみが利用します。第三者向けに提供、販売または貸与しません。

2. 利用目的

犬種解説動画の生成、動画メタデータの設定、運営者本人のYouTubeチャンネルへのアップロードおよび予約公開のために利用します。

3. YouTube API Services

本システムはYouTube API Servicesを利用します。利用にあたっては、YouTube API Services Terms of Service、YouTube Developer Policies、Google Privacy Policyその他の適用される規約を遵守します。

4. 禁止事項

不正アクセス、APIクォータの回避、誤解を招くメタデータの使用、権利侵害コンテンツの投稿、その他YouTubeまたはGoogleの規約に反する利用を行いません。

5. 変更・停止

安全性、法令、YouTubeまたはGoogleのポリシー変更に応じて、本システムの仕様変更または運用停止を行う場合があります。

6. お問い合わせ

本システムに関するお問い合わせは、wankokurashi.lab@gmail.comまでご連絡ください。
