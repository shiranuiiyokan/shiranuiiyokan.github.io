プライバシーポリシー

制定日・最終更新日：2026年9月11日

DogVideoFactory（以下「本システム」）は、運営者本人が所有するYouTubeチャンネルへ犬種解説動画をアップロードし、予約公開するための個人用システムです。本ポリシーは、本システムによるGoogleユーザーデータの取扱いを説明します。

1. 取得する情報と権限

本システムはGoogle OAuthを通じて、YouTubeへの動画アップロードに必要なスコープ https://www.googleapis.com/auth/youtube.upload の許可を取得します。本システムが扱うのは、運営者がアップロードする動画ファイル、動画タイトル、説明文、タグ、公開設定および予約公開日時です。

2. 利用目的

取得した権限とデータは、運営者本人のYouTubeチャンネルへ動画を自動アップロードし、指定時刻に予約公開する目的にのみ使用します。

3. 保存方法

OAuthのrefresh token、client IDおよびclient secretは、非公開GitHubリポジトリのGitHub Actions Secretsに暗号化して保存し、自動アップロード処理時にのみ利用します。トークンを公開リポジトリや公開Webページへ掲載しません。

4. 第三者提供・販売

Googleユーザーデータを第三者へ販売、貸与、広告利用または不必要に共有しません。動画公開のためにGoogle／YouTube API Servicesおよび自動処理基盤としてGitHub Actionsを利用します。

5. データの閲覧・変更・削除

本システムはYouTubeアカウント内の既存動画、登録チャンネル、コメント、視聴履歴等を読み取りません。また、既存動画を変更または削除する権限を要求しません。アップロード後の動画管理は運営者がYouTube Studioで行います。

6. 権限の取消し

運営者はGoogleアカウントの「サードパーティ製のアプリとサービス」設定から、いつでも本システムのアクセス権を取り消せます。取消し後は新たな動画アップロードができなくなります。

7. Google API Services User Data Policy

本システムによるGoogle APIから受け取った情報の使用および他のアプリへの転送は、Limited Use要件を含むGoogle API Services User Data Policyに準拠します。

8. 変更

利用する権限やデータ取扱いに変更がある場合、本ポリシーを更新します。

9. お問い合わせ

本システムに関する問い合わせは、OAuth同意画面に表示されるユーザーサポートメール宛にご連絡ください。
